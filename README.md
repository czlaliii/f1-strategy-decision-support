# F1 Strategy Decision Support System

## Thesis

Versenystratégiai döntéstámogató rendszer fejlesztése Forma 1 telemetriai adatok alapján.

## Overview

This project aims to develop a scalable data analytics and decision support system based on Formula 1 telemetry data.

The system will use:

- OpenF1 API
- PostgreSQL
- Apache Spark
- Python
- Machine Learning
- Plotly Dash

## Planned components

- Data ingestion pipeline
- Data preprocessing
- Exploratory data analysis
- Feature engineering
- Machine learning models
- Race strategy simulator
- Scalability benchmarking
- Interactive dashboard
